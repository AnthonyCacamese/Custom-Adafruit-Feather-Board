This is a Custom PCB designed to integrate Adafruit Feather nRF52840 into a broader electronic system. 
It was designed and tested in the University of Miami Mechanobiology Laboratory for initial use in a Smart Orthopedic Rehabilitation System.

The board features connections to each pin on the microcontroller using 1x2 Horizontal Molex connectors.
Multiple connections are provided to the 3.3V output and GND pins for greater wiring options.
Various thermal and EMI safety measures are implemented, including thermal relief spokes and via netting.
